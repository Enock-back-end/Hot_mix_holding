# Unwavering Builds

Build a modern, mobile-first, highly professional website for a construction and outdoor building company named "Unwavering Construction and Projects CC", servicing the Pretoria and Gauteng region. The website must NOT look like a generic AI template; it needs an authentic, premium, and trustworthy corporate aesthetic. Use a clean color palette featuring earthy tones (deep forest greens, warm timber browns, and slate gray) paired with plenty of white space and crisp typography.

Core Directives:

Mobile-First Design: The layout must be perfectly optimized for mobile phones, featuring a sticky header with a hamburger menu, easily tappable large buttons, and vertically stacked cards.

No Prices Displayed: This is a quote-based business. Do not include any price tags, "$" symbols, or pricing tables anywhere on the site.

Conversion Focus (Quotes): The primary goal is lead generation. Use strong Calls to Action (CTAs) that say "Request a Quote", "WhatsApp Us", or "Email for Estimate".

Page Structure & Components:

1. Header:

Left side: A designated placeholder area for an uploaded logo image.

Right side: A primary CTA button: "Get a Quote".

2. Hero Section:

A high-quality, realistic placeholder background image of a beautiful wooden cabin or composite deck.

Headline: "Premium Custom Cabins, Wendy Houses & Decking."

Subheadline: "Expert craftsmanship tailored to your space. Contact us today for a custom estimate."

Two prominent buttons side-by-side: A green button for "WhatsApp Us" and a secondary button for "Email Us".

3. Our Products (Grid Section):

Create a clean, image-led grid showcasing the following 6 product categories as individual cards:

Nutec Cabins

Log Cabins

Wendy Houses

Wooden Decking

Composite Decking

Pergola Shades

Each card should have a realistic placeholder image, a brief 2-sentence description of the materials/benefits, and a "Request Quote" button.

4. Sticky WhatsApp Button (Crucial):

Implement a Floating Action Button (FAB) in the bottom right corner with a WhatsApp icon that stays visible as the user scrolls.

5. Footer:

Include standard business contact details (Pretoria, South Africa), quick links, and a final "Email Us" text link.

Technical Link Requirements for Future Tracking:

Set all WhatsApp buttons to use a standard <a> tag with href="[https://wa.me/YOURNUMBER](https://wa.me/YOURNUMBER)".

Set all Email buttons to use an <a> tag with href="mailto:YOUR@EMAIL.COM".

Ensure these links are easily identifiable in the code so I can add onclick JavaScript tracking attributes later. and make sure the is portfolio
